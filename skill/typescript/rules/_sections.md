# 섹션

이 파일은 TypeScript 컨벤션 규칙의 섹션 순서, 영향도, 설명을 정의합니다.

## 1. Types and Contracts (types)
**TitleKo:** 타입과 계약
**Lead:** 기존 타입 재사용, 인덱스 접근 파생, 함수 변수 타입, unknown 좁히기, as const 객체, interface와 type 구분
**Impact:** HIGH
**Description:** 함수 시그니처와 커스텀 타입에 계약을 명시하고 기존 콜백과 타입을 재사용합니다.
독립된 객체 계약은 `interface`, 타입 계산과 조합은 `type`으로 선언합니다.
`as const` 객체로 값과 타입을 함께 정의하고 타입 단언 대신 `unknown`의 범위를 좁힙니다.

## 2. Naming and Module Boundaries (naming)
**TitleKo:** 이름과 모듈 경계
**Lead:** 루트와 소유자 상수 자리, 파일과 심볼 표기, 배럴 금지, @/ 경로, config/env, 타입 이름
**Impact:** HIGH
**Description:** 식별자와 경로, 가져오기, 공개 진입점, 상수 위치에 소유자와 출처를 드러냅니다.
타입 이름은 값의 역할과 수명을 나타내고 소유자 경로에 있는 정보를 반복하지 않습니다.
여기서 **소유자**는 자기 폴더가 있는 모듈 하나입니다.
그 폴더 안 파일은 그 소유자만 씁니다.

## 3. Functions and Helper Boundaries (functions)
**TitleKo:** 함수와 보조 함수 경계
**Lead:** const 화살표, 객체 매개변수, 보조 함수의 조건과 자리, 선언 순서, util 승격, 재할당과 push, 이름 짓기
**Impact:** MEDIUM
**Description:** 함수 선언 형태와 시그니처를 일관되게 유지합니다.
한 대표 함수 안에서 되풀이하는 계산은 식이면 그대로 적고 문장이 필요하면 지역 함수로 둡니다.
보조 함수는 결과가 드러나는 이름을 붙여 대표 안 지역 함수, 소유자 `_function`, 루트 `util` 중 한 곳에 둡니다.
변수는 재계산을 막거나 판정을 설명할 때만 만듭니다.
파일 안 선언 순서를 정하고 넓은 스코프에서 `let` 재할당과 `push`로 값을 누적하지 않습니다.

## 4. Values and Data Structures (values)
**TitleKo:** 값과 자료구조
**Lead:** 불변 정렬, Set과 Map, 체인 읽기, 상수 선언, 조회표 기준, es-toolkit, dayjs, 한 번만 판정
**Impact:** HIGH
**Description:** 값을 다루는 관용구를 한 가지로 고정합니다.
넘겨받은 배열은 제자리에서 바꾸지 않고 반복되는 조회는 `Set`과 `Map`으로 모읍니다.
객체의 값은 구조분해하지 않고 체인으로 읽어 출처를 남깁니다.
한 곳에서 쓸 값은 조회표로 우회하지 않고 사용처에서 직접 고릅니다.
뜻이 있는 숫자는 쓰는 자리에 적지 않고 상수로 선언합니다.
값 보조 함수는 직접 만들기 전에 `es-toolkit`에서 찾습니다.
날짜는 `dayjs`로 다룹니다.
같은 판정은 경계에서 한 번만 하고 결과를 데이터로 전달합니다.

## 5. Absence and Fallback Handling (absence)
**TitleKo:** 없는 값 다루기
**Lead:** 리터럴 기본값 금지, 경계에서 채우는 기본값, 타입이 보장하는 검사 생략, 없는 값 검사 자리
**Impact:** HIGH
**Description:** 값이 없을 수 있는 상태를 다루는 규칙을 모읍니다.
값이 없다는 사실은 임의의 기본값으로 감추지 않고 사용처까지 전달합니다.
타입이 이미 보장하는 것은 다시 검사하지 않습니다.
값이 들어오는 경계에서 한 번 검사하고 중간 함수는 검증된 타입을 사용합니다.

## 6. Comment Conventions (docs)
**TitleKo:** 주석 규약
**Lead:** 본문 주석과 구획 상자, 묶음과 블록에 두는 상자, 명사형 한국어, 상자 모양, 예외 이유
**Impact:** MEDIUM
**Description:** 주석은 `//` 줄 주석으로만 쓰고 모양은 상자와 한 줄 주석 둘입니다.
상자는 선언마다 달지 않고 묶음과 블록 위에 두며 안은 커밋 메시지처럼 요약 줄부터 씁니다.
한 줄 주석에는 그 줄에만 해당하는 이유를 적고 코드 내용을 반복하지 않습니다.
주석은 목적과 제약만 짧은 한국어 명사형으로 적고 규칙이 허용한 예외에는 확인할 수 있는 이유를 남깁니다.

## 7. Tooling (tooling)
**TitleKo:** 도구 설정
**Lead:** Biome으로 자동 검사할 규칙
**Impact:** MEDIUM
**Description:** 자동 검사할 항목은 Biome으로 설정합니다.
도구가 검사하지 못하는 항목은 리뷰에서 확인합니다.
